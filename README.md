# AgentIT Doctor

## MVP v0.1 - Windows Event Collector & Root Cause Prototype

AgentIT Doctor es un agente de diagnóstico para Windows que analiza eventos del sistema y genera hipótesis de causa raíz.

### Capacidades

- Windows Event Collection
- PowerShell Collector
- Event Collector
- Network Agent
- Root Cause Analysis

### Tecnologías

- Python
- Pydantic
- PowerShell
- GitHub
